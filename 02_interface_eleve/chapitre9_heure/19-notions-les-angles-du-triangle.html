Notions : les angles du triangle

Les 3 coins d'un triangle font toujours une demi-tarte : 180°.

ALa demi-tarte cachée dans chaque triangle

3 coins = 180°

Un triangle a 3 côtés et 3 angles (ses 3 coins). Si on découpe les 3 coins d'un triangle et qu'on les colle côte à côte, ils forment toujours une ligne droite : un angle plat, une demi-tarte, 180°.

Essaie : tire sur les points du triangle pour le déformer. Regarde les 3 coins à droite : ils forment toujours une demi-tarte.

✋ Tire sur les ronds blancs
💡 Dans tous les triangles, petits ou grands, pointus ou écrasés : angle 1 + angle 2 + angle 3 = 180°.
Pour trouver l'angle qui manque : additionne les deux angles connus, puis cherche combien il manque pour arriver à 180.
⚠️ Le petit carré dans un coin veut dire angle droit : 90°. On n'écrit pas « 90° », le carré suffit !

⚠️ Un seul angle droit ou obtus par triangle ! Deux angles droits, c'est déjà 90° + 90° = 180° : il ne resterait rien pour le 3e angle. Le triangle ne peut pas se fermer.
💡 Le triangle équilatéral a 3 côtés pareils… et 3 angles pareils. On partage la demi-tarte en 3 parts égales : 180° ÷ 3 = 60° chacun.
